# herdr-mods

Mods for the [Herdr](https://herdr.dev) desktop app, one folder each. Every folder has a
`RECIPE.md` (the brief to build it from scratch), a `preview.png`, and the `mods/<name>/`
to copy into `~/.config/herdr-app/mods/`.

| Mod | What it is |
|---|---|
| [on-screen](on-screen/) | Open what the terminal just printed, from the keyboard: `Cmd+Shift+O`, a number, a letter, and the file, folder or link on screen opens in its app, Finder, any editor or any browser; a command an agent asked you to run elsewhere runs in a fresh terminal beside the pane. Also Herdr's right-click menu. |
